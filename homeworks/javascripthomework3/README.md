JavaScript Homework - Conditionals & Loops!

A collection of JavaScript exercises focusing on basic input validation, conditional logic, loops, and string manipulation.

## About the Project
This repository contains solutions for homework assignments covering fundamental programming concepts in JavaScript, such as if/else statements, comparison operators, and loop control structures.

## Exercises Overview
* *Exercise 1–3:* Number checking, grading scales, and countdown loops with basic input handling.
* *Exercise 4–5:* Sum calculations and vowel counting logic with string formatting (.trim(), .toLowerCase()).
* *Exercise 6:* Age and name validation checks for club entry, VIP status, and promotional rules.
* *Exercise 7–8:* While-loop implementations and iteration adjustments to prevent infinite loops.
