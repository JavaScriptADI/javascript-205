 JavaScript Functions & Array Practice

This repository contains practical exercises focused on core JavaScript concepts, specifically working with functions and arrays.

## What This Assignment Covers
* *Functions:* Learning how to properly define and invoke functions, understanding how to pass parameters, and exploring the importance and role of the return statement.
* *Arrays & Loops:* Practicing how to iterate through arrays using loops, extract specific numbers or data based on conditions, and calculate final results.
