Labeled boxes.

[ CODE ]const name = "Luka" let age = 25 console.log(name) // Luka console.log(age + 1) // 26

25

= stores a value in a name. let can change later — age = age + 1. const is locked in. When unsure, start with const.

Your first useful program.

const price = 25 const qty = 3 const total = price * qty console.log(`Total: ${total} GEL`)

Variables + math + console.log, working together. The backtick string `...${ }` drops a value straight into the text — that's the backtick key (top-left), not a quote.

One button, both directions.

↻ Sync Changes  1↑
[ PUSH ↑ ]
Your commits go upfrom your disk to GitHub
[ PULL ↓ ]
New commits come downfrom GitHub to your disk

A commit alone is not backed up — it lives only on your machine. Only after [Sync] is it on GitHub. Commit, sync, sleep well.

[ 05 · AI TOOLS ]
25

Tutor. Not ghostwriter.

[ ALWAYS ]
  • Type every line yourself
  • Ask why, not just fix
  • Be able to explain what you keep
[ NEVER ]
  • Paste homework, submit the answer
  • Accept code you don't understand
  • Let autocomplete think for you — not in week one

This course builds a skill inside your head. AI can speed that up — or replace it. Same tool, opposite outcomes. You choose.
