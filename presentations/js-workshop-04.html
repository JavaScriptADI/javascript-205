What is an array?

An ordered list of values. Use arrays when order matters or you have a collection of items.

const nums = [1, 2, 3, 4] console.log(nums[0]) // 1 console.log(nums.length) // 4

04

Common array methods

push/pop
Add/remove at the end
shift/unshift
Remove/add at the start
forEach
Run a function for each element
map
Transform each element → new array
filter
Keep elements that match a test
reduce
Accumulate values into a single result
// example: map + filter const names = ["Ana","Bob","Cara","Dan"] const short = names.filter(n => n.length <= 3).map(n => n.toUpperCase()) console.log(short) // ["ANA","BOB"]

[ OBJECTS ]
05

What is an object?

A collection of key:value pairs. Use objects to model entities with named properties.

const user = { name: "Maya", age: 30, roles: ["admin","editor"] } console.log(user.name) // Maya console.log(user['age']) // 30

Access, methods, destructuring

Access
  • dot notation: user.name

[ NESTED ]
08

Arrays of objects and nested data

Common pattern: array of objects (e.g., list of users). Use map/filter/reduce to process.

const users = [ {id:1, name:'Ana'}, {id:2, name:'Ben'} ] const names = users.map(u => u.name) console.log(names) // ['Ana','Ben']

[ MUTABILITY ]
09

Don't mutate when you shouldn't

Shallow copy
  • Arrays: [...arr] or arr.slice()
  • Objects: {...obj} or Object.assign({}, obj)
Deep copy
  • structuredClone(obj) (modern)
  • JSON.parse(JSON.stringify(obj)) — lossy for functions/dates
Prefer returning new arrays/objects from functions instead of mutating inputs — makes reasoning and debugging easier.
