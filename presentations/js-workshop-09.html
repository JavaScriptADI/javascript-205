[ FIND IT ]
06

querySelector — find an element

You already know the selectors: they are the same ones you write in CSS.

document.querySelector("#score") // by id document.querySelector(".price") // by class — the FIRST match only document.querySelector("button") // by tag document.querySelectorAll(".price") // ALL matches — a list you can forEach

Nothing matches? You get null — and then null.textContent = … or null.addEventListener(…) gives the red error you will see most this month: Cannot set / Cannot read properties of null.

[ CHANGE IT ]
08

textContent — read and write the text

const score = document.querySelector("#score") console.log(score.textContent) // "0" score.textContent = 42 // the page now shows 42 console.log(score.textContent) // "42"
the page shows
console
0 · 42

Reading textContent always gives you a string — even after you wrote the number 42 into it. So keep your score in a number variable, and write it onto the page.

addEventListener — run code on a click

const like = document.querySelector("#like") let count = 0 like.addEventListener("click", () => { count++ like.textContent = count }) console.log("ready")
the page
console
ready

Same idea as Workshop 08: you hand over a function, and someone else calls it. Here the browser calls it, once per click. From step 3 on you can click the button yourself.
