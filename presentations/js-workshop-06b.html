Three ways to write a function

function double(n) { return n * 2 } // 1 declaration const doubleExpression = function (n) { return n * 2 } // 2 expression const doubleArrow = (n) => n * 2 // 3 arrow console.log(double(21), doubleExpression(21), doubleArrow(21)) // 42 42 42

A declaration is hoisted: you may call it above the line that defines it. A function stored in a const — a function expression, a function used as a value — exists only after that line has run.

Returning an object from an arrow

const bad = n => { value: n } console.log(bad(5)) // undefined const good = n => ({ value: n }) console.log(good(5)) // { value: 5 } const alsoGood = n => { // or use real braces return { value: n } }
console
undefined
{ value: 5 }
why
{ after => → JavaScript expects a body
({ … }) → JavaScript expects a value
when in doubt: braces + an explicit return

This is the single most common arrow bug. You will hit it the moment you write students.map(s => ({ name: s.name, average: … })) — remember the parentheses.

A function is a value

Everywhere a number can go, a function can go too.

const shout = (text) => text.toUpperCase() + "!" // in a variable const tools = { shout: shout, whisper: (t) => t.toLowerCase() } const list = [shout, tools.whisper] // in an array console.log(tools.shout("hi"), list[1]("HI")) // HI! hi console.log(shout) // [Function: shout] — the function itself console.log(shout("hi")) // HI! — the result of calling it
shout→the function itself — you can pass it around
shout("hi")→call it now, and use what it gives back

The parentheses are the call. A name with no parentheses is the function as a value — that difference is the whole next slide.

Passing a function into a function

function repeat(n, action) { for (let i = 0; i < n; i++) { action(i) // repeat calls it, not you } } repeat(3, (i) => console.log("Hi", i))

A function passed in as an argument is a callback — you hand it over, somebody else decides when to call it. A function that takes one, like repeat, is a higher-order function. Every array method in Part 3 works exactly this way.

Build our own filter

function filter(array, test) { const result = [] for (const item of array) { if (test(item)) { result.push(item) } } return result } console.log(filter([1, 2, 3, 4, 5, 6], n => n % 2 === 0)) console.log( filter(["sun", "planet", "moon"], w => w.length > 4) )

Three quick ones

  • 01What does const c = n => { n * 2 } return?undefined. Braces make a body, and the body has no return.
  • 02Fix this: const f = n => { double: n * 2 }const f = n => ({ double: n * 2 }) — wrap the object in parentheses.
  • 03What is the difference between repeat(3, greet) and repeat(3, greet())?The first hands over the function. The second calls greet immediately and hands over its result — almost always a bug.
